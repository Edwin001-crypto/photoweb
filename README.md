GITARI'S PHOTO GALLERY — Photography Website 📸
Author
Edwin Karani

Description

GITARI'S PHOTO GALLERY is a simple, visually appealing photography website created to showcase a collection of favorite photographs and celebrate the beauty of everyday moments.

The website features a welcoming hero section, a gallery of photographs, a short biography describing the purpose of the website, and a footer. It is designed with a warm, minimalist aesthetic, using neutral colors, elegant typography, and responsive layouts.

This project was developed as part of an independent project to practice and demonstrate fundamental HTML and CSS skills.

Features

.A homepage with an introduction to the photography website.
.A gallery showcasing favorite photographs.
.An About section describing the purpose and inspiration behind the website.
.A list of photography essentials.
.Custom CSS styling with a consistent color palette and typography.
.Hover effects and smooth scrolling.
.A responsive layout for desktop, tablet, and mobile screens.
.Semantic HTML elements and accessible image descriptions.

Project Setup Instructions

Follow these steps to download and run the project locally.

1. Clone the repository
Open your terminal and run:
git clone https://github.com/Edwin001-crypto/photoweb.git
2. Navigate to the project directory
cd photoweb
3. Open the project
Open index.html in your preferred web browser to view the website.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension to preview the page while developing.

4. Make changes
Edit index.html to update the content and photographs. Edit style.css to customize colors, typography, spacing, and layout.

No additional dependencies or package installations are required.

Learning Objectives

This project demonstrates the use of:
Common HTML elements, including headings, paragraphs, div, span, header, img, strong, and em.
Ordered and unordered lists.
CSS selectors, the box model, background colors, font families, and font weights.
Borders, overflow, block elements, and pseudo-classes.
Responsive layouts using CSS media queries.
Git version control and GitHub Pages deployment.
